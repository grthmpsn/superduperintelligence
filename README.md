# Super Duper Intelligence

Source for [superduperintelligence.org](https://superduperintelligence.org), a parody landing page.
Super Intelligence is so 2026. This is the version with a duper.

## What's here

One self-contained static page, `index.html`. There's no build step and no dependencies apart from Google Fonts.

## Running it locally

Open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server 8000
```

## Deploying

The Vercel project `super-duper-intelligence` deploys `main` automatically
(Framework: Other, Root Directory: blank, no build command).
